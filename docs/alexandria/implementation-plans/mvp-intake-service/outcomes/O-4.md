## Validation Criteria

- The Rust service initializes Sentry at startup using a DSN injected from Secrets Manager (or SSM Parameter Store); the DSN is never hard-coded, never in source, never in the Docker image plaintext.
- Panics in the Rust service code path are captured by Sentry automatically via the `sentry` crate's panic handler.
- Explicit `capture_error`-style calls in handled error paths are present at the upload-coordination, page-render, delete, and feedback-intake handlers; payload bytes (Debug Bundle bytes, Feedback message text, Feedback attachments) are NEVER included in Sentry event metadata.
- Sentry event IDs and links are NEVER surfaced to Reporters or Feedback Submitters in CLI output, page content, or Discord posts.
- The service emits structured JSON logs to stdout/stderr; Fargate forwards them to CloudWatch; key fields include timestamp, level, request ID, request path, status, duration, and error type (when applicable).
- An `/health` endpoint returns 200 OK with no body content beyond a minimal heartbeat; the ALB target group uses it as the default healthcheck.
- `/robots.txt` returns `Disallow: /` to prevent crawler indexing of capability URLs.

## Motivation

The library deliberately defers metrics and tracing in MVP per [[System - Service Topology]] and the Narrow Forever posture, but Sentry plus CloudWatch is the floor below which operating in production is irresponsible. [[Decision - Sentry for Service Errors, Not Bundle Processing]] is unusual in the library because it explicitly forbids a `bun.report`-shaped use of Sentry (Sentry-as-bundle-processor) and also names a positive use (service errors only). This outcome ensures the affirmative case is wired up correctly in MVP, including the redaction guard so payload bytes never escape to Sentry by accident. Tier is Should rather than Must because the headline Report and Feedback flows technically work without Sentry, but flying blind in production is a half-finished MVP — this outcome is what makes "deployed on Fargate" actually maintainable.
