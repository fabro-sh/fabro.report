## Validation Criteria

- A test client can `POST` to the upload-coordination endpoint and receive a presigned S3 PUT URL plus a capability URL of the form `https://fabro.report/r/<32-hex-chars>`.
- A test client can `PUT` a tarball (≤50 MB) directly to S3 using the presigned URL; S3 stores it under `<YYYY>/<MM>/<DD>/<id>/bundle.tar.gz`.
- Visiting the capability URL in a browser renders the SSR Report Metadata Page showing exactly four elements (Report ID, upload timestamp, bundle size, delete affordance) — no fifth element, no `bun.report`-style content rendering.
- The page matches the C2 design system (Geist + JetBrains Mono, dark-mode-only palette, semantic tokens) and the C3 layout (~500px centered column, terminal-style metadata rows, secondary text-link delete affordance, symbol-only footer).
- The page passes WCAG 2.2 AA: semantic HTML, keyboard navigation, accessible delete confirmation, no color-only signaling.
- The delete affordance triggers a client-side native `confirm()`; on confirm, the service removes both the metadata sidecar and the bundle object; subsequent GETs to the URL return a generic 404.
- A capability URL whose ID does not exist (never minted, expired, or deleted) returns a generic 404 with no tombstone messaging.
- Report ID is 32 lowercase hex characters drawn from a CSPRNG (128 bits of entropy); IDs are not sequential, timestamp-derived, or content-derived.

## Motivation

The Report flow is the headline reason `fabro.report` exists — it is the pickup point for Debug Bundles that lets the Fabro team retrieve crashes from self-hosted users. Without an end-to-end Report flow there is no product. Capability-URL access (no auth, no accounts, URL-leak-equals-access by design) is the single most load-bearing security choice in the library; this outcome validates that the service implements it correctly down to the ID-entropy floor. The receipt page must hit the C2/C3 visual bar in MVP rather than ship as a placeholder, because a half-finished receipt page is a half-finished product surface and there is no second page to compensate.
